# 新模型優先與本輪修正

場景不得混用舊模型。V5 特別版收錄 61 種新建模型，不沿用原先 87 種圖鑑清單。

## 模型來源

- 新主角載入完成前顯示準備畫面；失敗停留於明確錯誤訊息，不顯示舊主角。
- 61 種已有新建模來源可在場景使用：13 種骨架 GLB，48 種新建曲面模型加分組關節動畫。
- 原本直接引用 V4 GLB 的 28 種停止載入及自然出現；舊捕捉歷史留在存檔相容資料，不計入 V5 特別版圖鑑。
- 48 種分組關節動畫已有可播放的模型，仍不能等同於每一種都完成逐格美術驗收。
- 首次階段御三家已檢查走路片段：妙蛙種子與波加曼使用既有骨架，其餘 10 種有實際腿部關節變化。

## 雷達與道館

- 雷達固定於最右上角，建築短名與 NPC 使用 7 像素字體；鄰近標籤嘗試不同垂直位置避讓，NPC 圓點持續顯示。
- 道館選單依寬度切換一／兩欄，限定視窗高度並允許捲動；卡片文字不截斷。
- 四場地為電力線路、超能力同心圓、音波舞台、療癒十字場；邊界與尺寸沿用現有遊戲資料。
- 攻擊演出分別為電弧、念力軌環、音波、旋轉蛋群，搭配首領 Attack 動作；碰撞半徑、障礙持續時間與傷害規則未改。
- 血條投影到首領頭頂，寬度 116 CSS 像素；首領出框時不把血條黏在畫面中央。
- 進出道館立即重設相機跟隨，避免從相距 500 單位的場景平滑飛越而看到天空。
