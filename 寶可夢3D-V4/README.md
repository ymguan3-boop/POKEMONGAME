# 寶可夢 3D 遠征：神奧夏日版 (3D-V4)

以 Three.js 打造的 3D 寶可夢收集遊戲。在神奧地區的夏日開放地圖中探索、捕捉寶可夢、挑戰特殊道館，並收集傳說寶可夢。

- **遊玩網址**：<https://ymguan3-boop.github.io/POKEMONGAME/寶可夢3D-V4/>
- **入口檔案**：同資料夾的 `index.html`（與 `game.html` 相同內容）
- **3D 引擎**：Three.js、GLTFLoader、GLB 模型（`models/`，46 個模型全部內建於專案）

---

## 🎮 遊玩方式

### 操作控制

| 按鍵 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` | 移動角色 |
| `空白鍵`（長按） | 蓄力丟擲寶貝球 |
| `L` | 鎖定 / 切換目標 |
| `U` | 取消鎖定 |
| `B` | 餵食樹果 |
| `H` | 自動導航至寶可夢中心 |

- 手機／平板提供虛擬搖桿與觸控按鈕，可直接遊玩。
- 畫面右上角雷達可顯示附近野生寶可夢位置。

### 捕捉機制

瞄準鎖定野生寶可夢後長按投球，捕捉率依球種與目標而定：

| 球種 | 一般寶可夢 | 特殊寶可夢 |
| ---- | ---------- | ---------- |
| 普通寶貝球 | 75% | 45% |
| 進階寶貝球 | 95% | 70% |
| 大師球 | 99% | 99% |

- 餵食樹果可額外提升 **15%** 捕捉率（非大師球最高 95%）。
- 樹果另可使目標**冰凍定身 5 秒**，方便對戰與捕捉。
- 大木博士不定期會在野外投遞補給（進階球 ×10 或大師球 ×5）。

### 進化與解放

- 初期野外只會出現 1 階基礎寶可夢。
- 收集達 **5 種以上** 基礎寶可夢後，地圖解放，二階與三階進化型態將開始隨機出現。

## 🏟️ 特殊道館挑戰（4 座）

道館為純淨對戰場景，**不消耗寶貝球**（無限使用）；進階球 40 傷害、大師球 90 傷害。擊敗首領後，該寶可夢會在野外現身並納入圖鑑。

| 道館 | 首領 | HP | 通關獎勵 |
| ---- | ---- | -- | -------- |
| ⚡ 皮卡丘道館 | 巨型皮卡丘 | 100 | 皮卡丘頭套（每 2 分鐘發動十萬伏特全域時停 15 秒） |
| 🔥 噴火龍道館 | 噴火龍 | 200 | 噴火龍翅膀（浮空能力、移速 +20%） |
| 🎤 胖可丁道館 | 巨型胖可丁 | 160 | 胖可丁變身套裝（球數上限 +30） |
| 🥚 幸福蛋道館 | 幸福蛋 | 240 | 幸福蛋變身套裝（球數上限 +30） |

---

## 👗 變身套裝機制

- **一次只能裝備一套**；胖可丁／幸福蛋兩套皆可使寶貝球上限 **+30**。
- 通關胖可丁道館解鎖**胖可丁套裝**、通關幸福蛋道館解鎖**幸福蛋套裝**。
- 套裝可在主選單「變身套裝」自由切換，裝備後角色外觀即變身。

## 🛠️ 技術細節

- **模型**：`models/` 內含 46 個 GLB（44 種寶可夢 + 訓練家 + 寶可夢中心），全部打包於專案內，部署後同源載入、無跨域問題。
- **存檔**：進度自動儲存於瀏覽器（本機模式）。
- **主選單**：道館挑戰設施 / 變身套裝 / 神奧圖鑑 / 遊戲說明 / 重置進度。
