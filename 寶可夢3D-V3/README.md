# 寶可夢 3D 遠征：道館挑戰與進化解放版（3D-V3）

這是以 Three.js 製作的單檔 3D 寶可夢探索與捕捉遊戲，主題為豐緣地區風格的道館挑戰與進化解放。遊戲原始檔為 `POKEMON3D-3代.html`，直接由瀏覽器載入即可遊玩。

- **遊玩網址**：<https://ymguan3-boop.github.io/POKEMONGAME/寶可夢3D-V3/>
- **原始遊戲檔**：`POKEMON3D-3代.html`
- **資料夾入口**：`index.html`
- **技術**：HTML、JavaScript、Three.js r128、Tailwind CSS CDN、Web Audio API

## 圖鑑與寶可夢

本版本的程式圖鑑共 **42 種**：

- **進化鏈與一般野外寶可夢**：木守宮、森林蜥蜴、蜥蜴王；火稚雞、力壯雞、火焰雞；水躍魚、沼躍魚、巨沼怪；土狼犬、大狼犬；蛇紋熊、直衝熊；刺尾蟲、甲殼繭、狩獵鳳蝶；蓮葉童子、蓮帽小童、樂天河童；橡實果、長鼻葉、狡猾天狗；傲骨燕、大王燕；長翅鷗、大嘴鷗；拉魯拉絲、奇魯莉安、沙奈朵；懶人獺、過動猿、請假王；可可多拉、可多拉、波士可多拉；阿勃梭魯。
- **傳說／幻之寶可夢**：固拉多、蓋歐卡、烈空坐、基拉祈。
- **道館首領捕捉目標**：皮卡丘、噴火龍。

初期野外以 14 種基礎型態隨機生成；成功收集至少 **5 種**後，會解放二階與三階進化型態的隨機出現。圖鑑會記錄解鎖狀態與每種捕捉數量，每種預設收集上限為 3 隻。

## 道館挑戰

共有 **2 座特殊道館**，可從主選單「道館挑戰設施」進入：

| 道館 | 首領 | HP | 通關獎勵 |
| --- | --- | ---: | --- |
| 皮卡丘道館 | 巨型皮卡丘 | 100 | 皮卡丘頭套 |
| 噴火龍道館 | 噴火龍 | 200 | 噴火龍翅膀 |

道館是獨立的純戰鬥場景，不生成野生寶可夢與天氣干擾；挑戰期間寶可夢球不會消耗。進階球命中可造成 40 點傷害，大師球命中可造成 90 點傷害。首領被擊敗後會解鎖對應獎勵，並在大世界生成可捕捉的特殊寶可夢。

## 捕捉與道具

1. 在大世界鎖定野生寶可夢。
2. 長按空白鍵或畫面投球按鈕蓄力。
3. 放開後投出寶可夢球，命中目標會進入捕捉判定。
4. 捕捉成功會更新圖鑑、數量、HUD 與本機存檔；失敗則目標回到場景。

可使用普通球、進階球與大師球；樹果可餵給目前鎖定的目標，增加捕捉機會。大木博士補給會在地圖投放進階球或大師球。抵達寶可夢中心可補滿普通球。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動主角 |
| 長按 `空白鍵` | 蓄力並投球 |
| `L` | 鎖定／切換目標 |
| `U` | 取消鎖定 |
| `B` | 使用樹果 |
| `H` | 自動導航至寶可夢中心 |
| 滑鼠拖曳／觸控拖曳 | 旋轉鏡頭 |
| 虛擬搖桿與畫面按鈕 | 手機、平板操作 |

右上角雷達會顯示附近寶可夢與物品的位置；底部操作列則會顯示桌面版快捷鍵。

## 變裝與通關獎勵

V3 的變裝採「通關後自動裝備」規則：

- 通關皮卡丘道館後顯示皮卡丘頭套；頭套每 120 秒可觸發一次全域時間停止，持續 15 秒。
- 通關噴火龍道館後顯示噴火龍翅膀；主角移動速度提高，並呈現浮空效果。
- 道館獎勵會寫入瀏覽器 `localStorage`，重新整理後仍可恢復。

## 技術與檔案說明

- 場景、主角、寶可夢、道具與道館首領以 JavaScript／Three.js 幾何、材質與燈光即時建立。
- 進度以瀏覽器 `localStorage` 保存，主要存檔鍵為 `pokemon3d_gen3_v4_winter`。
- Three.js 與 Tailwind CSS 由 CDN 載入，因此第一次開啟需要網路連線。
- 本專案保留原始單檔 HTML，沒有拆分或改寫遊戲邏輯。
