# POKEMONGAME

寶可夢 3D 互動遊戲的存放空間，使用 Three.js 建置，並透過 GitHub Pages 免費公開遊玩。

## 資料夾說明

| 資料夾 | 內容 |
| ------ | ---- |
| `寶可夢3D-V4/` | 遊戲主程式（`index.html` / `game.html`）、圖檔與全部 46 個 GLB 3D 模型（`models/`） |

## 遊戲

**寶可夢 3D 遠征：神奧夏日版** — 在第 4 代神奧地區的 3D 開放地圖中自由探索、捕捉寶可夢、挑戰道館與收集傳說寶可夢。

- 遊玩網址：<https://ymguan3-boop.github.io/POKEMONGAME/寶可夢3D-V4/>
- 詳細說明請見 [`寶可夢3D-V4/README.md`](寶可夢3D-V4/README.md)

## 技術

- Three.js + GLTFLoader
- 全部寶可夢模型以 GLB 格式包入專案（`models/`），無需外部伺服器即可載入
- 進度支援瀏覽器本機存檔
