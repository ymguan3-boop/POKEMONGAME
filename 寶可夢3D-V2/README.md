# 寶可夢 3D 遠征：進化與傳奇（3D-V2）

這是第二代／城都風格的 3D 寶可夢探索與捕捉遊戲。玩家在開放場景中移動、鎖定目標、投擲寶可夢球、收集進化鏈，並依圖鑑進度解鎖傳說寶可夢。

- **遊玩網址**：<https://ymguan3-boop.github.io/POKEMONGAME/寶可夢3D-V2/>
- **原始遊戲檔**：`POKEMON3D-2代.html`
- **資料夾入口**：`index.html`
- **技術**：HTML、JavaScript、Three.js、Tailwind CSS CDN、Firebase／Firestore 存檔

## 圖鑑與寶可夢數量

本版本圖鑑共 **30 種**：

| --- | --- |
| 草系進化鏈 | 菊草葉、月桂葉、大竺葵 |

## 道館與主線

本 V2 原始程式**沒有道館挑戰模組**，也沒有道館首領或道館通關獎勵；主線目標是完成圖鑑、解鎖進化型態並捕捉傳說寶可夢。

傳說寶可夢的出現條件：

- 圖鑑解鎖進度達 30%：雷公出現。
- 圖鑑解鎖進度達 50%：炎帝出現。
- 圖鑑解鎖進度達 80%：水君出現。
- 圖鑑只剩最後一種未解鎖時：洛奇亞出現。
- 捕捉洛奇亞後會顯示完成遊戲的勝利面板。

## 進化與收集規則

- 初期場景從 12 種基礎型態隨機生成。
- 同一物種捕捉達 **2 隻**後，對應進化型態會加入後續生成池。
- 每種寶可夢的收集上限為 **3 隻**；達上限後會停止該物種的正常補位生成。
- 每完成一種寶可夢的 3 隻收集，所有基礎捕捉率永久增加 1%，寶可夢球持有上限增加 5 顆。
- 捕捉成功會彈出名稱、屬性、3D 模型與圖鑑說明。

## 捕捉、道具與機率

玩家可使用普通球、進階球與大師球：

- 一般寶可夢的基礎捕捉率依進化階段約為 20%～70%。
- 雪拉比的基礎捕捉率為 10%。
- 傳說寶可夢依逃脫率計算：雷公約 30%、炎帝約 20%、水君約 15%、洛奇亞約 5%。
- 樹果額外增加 10% 捕捉率，每隻目標只能餵食一次。
- 進階球額外增加 15% 捕捉率。
- 大師球額外增加 20% 捕捉率。
- 樹果與特殊球效果可以疊加。
- 普通球初始上限為 30 顆；收集滿級物種後，每種再增加 5 顆。
- 寶可夢中心附近會生成樹果；靠近寶可夢中心可補滿普通球。
- 大木博士會在約 1～3 分鐘間隔投放補給品：大師球、進階球或時間停止器。
- 時間停止器會讓場上寶可夢停止移動 20 秒。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動主角 |
| 長按 `空白鍵` | 蓄力並投球 |
| `L` | 鎖定／切換目標 |
| `U` | 取消鎖定 |
| `B` | 餵食樹果 |
| `H` | 自動導航至寶可夢中心 |
| 滑鼠拖曳／觸控拖曳 | 旋轉視角 |
| 觸控方向鍵與畫面按鈕 | 手機、平板操作 |
| 右上角雷達 | 查看附近寶可夢與補給位置 |

## 變裝機制

本 V2 原始程式**沒有變身套裝或服裝切換機制**。主角維持小智風格的固定外觀，遊戲獎勵集中在圖鑑完成度、捕捉率永久提升、寶可夢球上限提升，以及傳說寶可夢解鎖。

## 技術與存檔

- 場景、主角、寶可夢、樹果、補給品與捕捉特效由 Three.js 幾何與材質即時建立。
- 遊戲使用 Three.js Canvas、雷達 Canvas、鍵盤事件、滑鼠／觸控事件與虛擬方向鍵。
- 程式包含 Firebase Authentication／Firestore 存檔流程；若執行環境未提供有效 Firebase 設定，雲端存檔可能無法同步。
- Three.js 與 Tailwind CSS 使用 CDN 載入，首次開啟需要網路連線。
- 本專案保留原始單檔 HTML，沒有改寫 V2 遊戲邏輯。
