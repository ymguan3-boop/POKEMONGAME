# 寶可夢 3D 遠征：進化與傳奇（3D-V1）

這是第一代／關都風格的 3D 寶可夢探索與捕捉遊戲。玩家可在開放場景中移動、鎖定寶可夢、投擲寶可夢球、收集進化型態，並依圖鑑進度解鎖傳說寶可夢與超夢。

- **遊玩網址**：<https://ymguan3-boop.github.io/POKEMONGAME/寶可夢3D-V1/>
- **原始遊戲檔**：`POKEMON3D-1代.html`
- **資料夾入口**：`index.html`
- **技術**：HTML、JavaScript、Three.js、Tailwind CSS CDN、Firebase／Firestore 存檔

## 圖鑑與寶可夢數量

本版本圖鑑共 **22 種**：

| 分類 | 寶可夢 |
| --- | --- |
| 電系 | 皮卡丘、雷丘 |
| 草／毒進化鏈 | 妙蛙種子、妙蛙草 |
| 水系進化鏈 | 傑尼龜、卡咪龜 |
| 火系進化鏈 | 小火龍、火恐龍 |
| 一般／飛行進化鏈 | 波波、比比鳥 |
| 草／毒進化鏈 | 走路草、臭臭花 |
| 岩石／地面進化鏈 | 小拳石、隆隆石 |
| 單體寶可夢 | 伊布、胖丁、耿鬼、夢幻 |
| 傳說／特殊寶可夢 | 閃電鳥、火焰鳥、急凍鳥、超夢 |

初始野外生成池包含 11 種基礎型態：皮卡丘、妙蛙種子、傑尼龜、小火龍、伊布、胖丁、耿鬼、夢幻、波波、走路草與小拳石。

## 道館與主線

本 V1 原始程式**沒有道館挑戰模組**，也沒有道館首領、道館戰鬥或道館通關獎勵。遊戲主線是完成圖鑑、解鎖進化型態，最後捕捉超夢。

傳說寶可夢的出現條件：

- 圖鑑解鎖進度達 30%：閃電鳥出現。
- 圖鑑解鎖進度達 50%：火焰鳥出現。
- 圖鑑解鎖進度達 80%：急凍鳥出現。
- 圖鑑只剩最後一種未解鎖時：超夢出現。
- 捕捉超夢後會顯示遊戲完成面板。

## 進化與收集規則

- 初期場景從 11 種基礎型態中隨機生成。
- 同一物種捕捉達 **2 隻**後，對應進化型態會加入後續補位生成。
- 程式定義的進化路徑為：皮卡丘→雷丘、妙蛙種子→妙蛙草、傑尼龜→卡咪龜、小火龍→火恐龍、波波→比比鳥、走路草→臭臭花、小拳石→隆隆石。
- 捕捉成功會更新圖鑑、捕捉數量，並彈出名稱、屬性、3D 模型與圖鑑說明。
- 捕捉傳說寶可夢時會顯示特殊捕捉提示；超夢捕捉成功會結束主線。

## 捕捉與道具

- 普通寶可夢使用基礎捕捉判定。
- 傳說寶可夢具有不同逃脫率：閃電鳥 30%、火焰鳥 50%、急凍鳥 70%、超夢 80%。
- 可使用普通球、進階球與大師球；進階球與大師球會提高捕捉機會。
- 樹果可餵給鎖定目標，增加捕捉機會。
- 寶可夢中心附近會生成樹果與補給品。
- 大木博士會投放補給品，並可能提供特殊球或時間停止效果。
- 雷達會以不同顏色標示一般寶可夢與傳說寶可夢。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動主角 |
| 長按 `空白鍵` | 蓄力並投球 |
| `L` | 鎖定／切換目標 |
| `U` | 取消鎖定 |
| `B` | 餵食樹果 |
| `H` | 自動導航至寶可夢中心 |
| 滑鼠拖曳／觸控拖曳 | 旋轉視角 |
| 觸控方向鍵與畫面按鈕 | 手機、平板操作 |
| 右上角雷達 | 查看附近寶可夢與補給位置 |

## 變裝機制

本 V1 原始程式**沒有變身套裝或服裝切換機制**。主角維持小智風格的固定外觀，主要獎勵是圖鑑進度、進化型態解鎖、傳說寶可夢出現與超夢完成面板。

## 技術與存檔

- 場景、主角、寶可夢、樹果、補給品與捕捉特效由 Three.js 幾何與材質即時建立。
- 程式使用 Three.js Canvas、雷達 Canvas、鍵盤、滑鼠、觸控與虛擬方向鍵。
- 程式包含 Firebase Authentication／Firestore 存檔流程；未提供有效 Firebase 設定時會使用單機模式。
- Three.js、Tailwind CSS 與 Firebase 模組由 CDN 載入，首次開啟需要網路連線。
- 本專案保留原始單檔 HTML，沒有改寫 V1 遊戲邏輯。
