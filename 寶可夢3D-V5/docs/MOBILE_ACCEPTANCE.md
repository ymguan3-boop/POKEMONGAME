# 直立手機驗收

依使用者 2026-10-09 補充要求，以直立手機遊玩為主要介面方向，保留 V4 左下搖桿及右下蓄力丟球、換球、餵食、鎖定；不改捕捉機率、投射公式、碰撞或移動速度。

## 本次調整

- 直立鏡頭使用 58 度垂直視角，地面跟隨距離為桌面設定的 76%；有近處高空寶可夢時追加最多 3 單位取景空間，總距離限制 7.2–15 單位；保留第三人稱高斜角與主角全身。
- 支援瀏海與底部安全區，主要按鈕至少 44 CSS 像素；投球按鈕 72 像素、搖桿 112 像素。
- 道具入口收進 V4 主選單，中央留給主角與附近寶可夢。手機仍可拖動畫面轉向，雷達可收合。
- 搖桿及鏡頭各自追蹤觸控識別碼，避免另一手指干擾；取消觸控停止蓄力，視窗失焦重設搖桿。
- 觸控放開後抑制瀏覽器合成點擊，避免長按放開後重新蓄力。
- 上衣藍色色塊改為共用衣服曲面，移除穿入胸口的平面色塊。

## 可重跑檢查

本機伺服器：`node tools/serve-v5.cjs`。
手機：`node tools/qa-v5-mobile.cjs`；桌面回歸：`node tools/qa-v5-integration.cjs`。

測試尺寸為 360×640、390×844、430×932，檢查全身入鏡、附近波加曼入鏡、畫面無水平溢出、按鈕尺寸、雙指移動與蓄力放球、選單道具入口。截圖及報告位於 `qa/portrait-*`。

測試採 Chromium 手機觸控模擬，**不是實體 iPhone／Android 效能驗收**。投影高度檢查使用站立高度參考線，仍需搭配實際截圖檢查外觀；不能將此測試當作全部 87 種模型或手機幀率均已通過。

整體 V5 尚未完成逐種模型、完整動畫與最終效能驗收，仍為本機開發預覽。
