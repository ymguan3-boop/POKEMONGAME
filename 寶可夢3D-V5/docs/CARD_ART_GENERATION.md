# V5 特別版卡牌美術交接

本版以內建 `image_gen` 工具產生 Q 版 2D 插畫，沒有使用 Blender 或建模技能。每次輸入四隻 V5 新 3D 模型的參考圖，要求輸出 2×2 等大四宮格，再用 `tools/crop-v5-card-sheet.py` 切成四張 WebP。插畫中不烘焙名稱、HP 或招式；文字由網頁排版。

來源清單及模型雜湊見 [`../cards/model-sources.json`](../cards/model-sources.json)。每隻角色的原始模型縮圖由 `tools/export-v5-card-refs.cjs` 產生，存於 `cards/model-thumbs/`；本機四宮格參考圖在 `cards/references3d/`，屬產製工作檔，不納入公開網站。已完成卡圖在 `cards/art/`，公開遊戲只透過 `js/card-art.js` 載入有完成的項目。

## Prompt set

共通指令：「以所附四個 V5 3D 模型為角色身形、配色及五官參考；同位置輸出四格等大的正方形，可安全切成四張。畫風為圓潤、可愛、大眼、動作活潑的手繪 2D Q 版卡通。每格角色完整留在界線內，配上對應屬性、場景與動勢；不可輸出文字、數字、Logo、卡框、浮水印或 3D 渲染。」

每組再按模型加入四隻不同角色的辨識特徵與動作，例如草系藤鞭、火系跳躍與火花、水系水泡、飛鳥水平飛翔與連接身體的腳、超夢念力光球。第 8、9、10～12 組曾遇生圖輸出審查，改用簡潔的 2D 童書描述後完成。
